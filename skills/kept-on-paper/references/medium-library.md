# Medium Library

为每张作品选择一种主要媒介和最多一种相容辅助媒介。媒介必须通过形状、明度、边缘、笔触与材料行为被识别；不能只靠色调名称区分。

## Identity-bearing Core Router

- 身份性人物、重要动物、手势或接触关系作为核心时，默认从 `GOUACHE`、`DIGITAL_PAINTING`、`ILLUSTRATION` 中选择；只有需要明显厚重、沉静或物质感时才选择 `OIL_PAINTING`。
- 铅笔、彩铅、墨线、数字蜡笔和素描底线只用于局部结构、动作路径、关系隐喻、记忆场或边缘过渡，不得成为身份性核心的统一成像方式。
- `CRAYON` 与 `WATERCOLOR` 可作为无身份风险物件、植物、路径、光线和环境核心的主要媒介；用于人物或重要动物时必须由用户明确指定，并仍须保持脸、姿态和接触点清楚。
- 媒介选择服从核心事实和重构目标，不因“更手作”而把人物统一铅笔化，也不因“更完整”而恢复整幅摄影空间。

## ILLUSTRATION

- 形状：两至五个经过设计的连续主形，清晰负形，避免贴纸碎片。
- 明度：三至五级，核心对比最明确，记忆场压至一至三个层级。
- 边缘：主体轮廓选择性清楚；非关键段断开或融入纸面。
- 笔触：少量手工线，不以均匀描边包围每个对象。
- 材料：平面颜料或印刷墨感，但纸纤维不成为主角。
- 相容辅助：`CRAYON`、`WATERCOLOR`。

## OIL_PAINTING

- 形状：由大色团塑造，不堆砌完整背景。
- 明度：核心允许四至六级；记忆场压为薄涂大形。
- 边缘：一处到两处厚实硬边，其余擦薄、刮开或失焦。
- 笔触：可见但有方向，跟随动作、轮廓和空间势能。
- 材料：局部不透明堆色与干刷底色；在白色底料画布上保留克制底痕，禁止满幅厚涂和概念艺术场景。
- 相容辅助：`DRAWING_UNDERLINE`，只作为记忆场底线。

## CRAYON

- 形状：蜡质覆盖形成大形，保留纸面缺口，不画儿童贴纸轮廓。
- 明度：由压力和叠色产生三至五级。
- 边缘：断裂、擦抹、颗粒化；核心关键轮廓压力更稳定。
- 笔触：短向线服务形体，长向线服务运动或场域。
- 材料：可见蜡质颗粒和局部覆盖，不甜美卡通化。
- 相容辅助：`WATERCOLOR`、少量 `GOUACHE`。

## WATERCOLOR

- 形状：一至三个相连色域，以水痕和负形组织，不做透明风景明信片。
- 明度：保留纸白，核心以叠染形成最清楚的三至五级。
- 边缘：湿边、回流边与少量干边并存；关键接触点用干边锁定。
- 笔触：方向性水迹服务动作与环境余韵。
- 材料：颜色在局部相融；`OPEN_SPACE` 保持所选纸面干净，`QUIET_FILLED_FIELD` 只允许来源明确的连续低信息薄色域。
- 相容辅助：`INK_LINE`、`CHINESE_BRUSH`。

## GOUACHE

- 形状：不透明、被简化的大色面，核心形体最完整。
- 明度：三至五个块面层级，避免水彩式全透明风景。
- 边缘：干湿边变化，重点处厚、记忆场处薄或擦去。
- 笔触：少量平涂笔触和干刷，不能把每个环境对象画全。
- 材料：粉质遮盖感与纸面摩擦感。
- 重构要求：人物或动物核心可以保留较完整块面；环境必须删减、移位或压成一个辅助主形。若把人物、树木、建筑和地面全部按原位置水粉化，判定为滤镜式重画。
- 相容辅助：`CRAYON`、`INK_LINE`。

## DIGITAL_PAINTING

- 形状：宽笔刷构成大形，拒绝概念艺术式完整场景和照片贴图。
- 明度：核心四至六级，场域二至三级。
- 边缘：有目的地切换软硬边，身份和接触线索最清楚。
- 笔触：可见数字笔刷节奏，不使用渐变色块和 UI 式几何。
- 材料：模拟绘画响应而非摄影滤镜。使用 `PURE_WHITE_DIGITAL` 时保持中性或极轻冷白，无纸纤维、水渍、扫描噪声和泛黄；用宽笔刷与受控软硬边建立空间。
- 重构要求：`OPEN_SPACE` 中只绘制核心、一个记忆场主形和必要痕迹，让纯白数字基底真实露出；不得以低对比数字笔刷填满画布。`QUIET_FILLED_FIELD` 也必须压平、合并并改变原摄影空间，禁止完整数字水粉风景化。
- 相容辅助：`ILLUSTRATION_LINE`、`DIGITAL_CRAYON`。

## CHINESE_PAINTING

- 形状：以势、气和留白组织一个主形，不复制传统题材模板。
- 明度：墨色或矿物色控制在三至五级，核心浓度最高。
- 边缘：干湿、浓淡、飞白与没骨边共同出现。
- 笔触：每一笔承担轮廓、方向或气候信息，不作无意义皴法堆叠。
- 材料：纸面渗化受控；根据来源选择暖象牙白或冷白棉纸，不施全局古旧黄。
- 相容辅助：`WATERCOLOR`、`MINERAL_GOUACHE`。

## 辅助媒介限制

- 只进入主记忆场和可选过渡痕迹，不进入核心身份与关键接触点。
- 不超过明确绘制面积约 20%。
- 只承担一种职责：方向、底层结构、色彩回声、边缘过渡或材料对比。
- 若辅助媒介需要自己的独立构图、色域或叙事才能成立，改为 `NONE`。
- 来源图形回声已经承担相同的方向、底层结构或色彩回声职责时，关闭辅助媒介或图形回声之一，不能双重表达。

## 媒介一致性测试

1. 转为灰度后，仍能从边缘和笔触辨认主要媒介。
2. 隐藏辅助媒介后，核心仍完整；显示辅助媒介后，它只加强主记忆场。
3. 更换颜色不应把一种媒介误判为另一种。
4. 更换基底后，媒介仍须保持可信：数字板绘不伪装成宣纸，油画不伪装成透明水彩。
5. 核心为人物或重要动物时，缩小观看仍能通过姿态、脸部关系和接触点识别；若只剩统一铅笔轮廓或蜡笔轮廓则失败。
6. 输出若保留原图对象布局、面积分区和景深，仅改变笔触或材质，则无论媒介多明显都判定失败。
