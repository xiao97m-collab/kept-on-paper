# Palette System

颜色先服从照片事实和视觉层级，再服从个人偏好。目标是“来源可追溯、强弱有因的色彩重组”，不是固定降低饱和度，也不是为整张纸加滤镜。

## 1. 来源色提取

先记录 `causal_palette`，再选色板：

```yaml
dominant_relation:
light_source_and_time:
material_response:
identity_colors: []
colored_dark:
area_relation:
forbidden_drift: []
```

它说明主色为何出现、占多大面积、照到什么材料以及什么变化会让原图失去味道。不能只列“青色、米白、酒红”后确认它们各自仍有一小块；主导比例、冷暖关系和光材反应同样受保护。

从原照片选三至五个有意义的颜色角色：

- `SOURCE_MAIN`: 最大或最能代表时空气氛的颜色。
- `SOURCE_SUPPORT`: 与主色共同构成环境关系的颜色。
- `IDENTITY_COLOR`: 帮助认出主体、物件或事件的关键颜色。
- `LOCAL_ACCENT`: 面积小但有记忆价值的颜色。
- `COLORED_DARK`: 来自原图阴影倾向的深色，不默认使用纯黑。

合并肉眼近似的颜色，并按角色决定保持、降低或强化饱和度。原图中本来鲜明且承担识别或情绪功能的颜色可以保留强度；身份色不能消失。若原图色彩贫乏，保留其明度关系，再进入个人校准。

## 2. Color Direction

- `AUTO`：根据来源色、时间、光线、媒介和构图选择下列一个方向；不得把“低饱和”当成无条件默认值。
- `SOURCE_LED`：保留原图最有意义的色彩关系，可适度简化和重新分配面积，但不主动把所有颜色做灰。
- `LOW_SATURATION`：有意识降低综合色度，以有色暗部、纸面和小面积识别色维持层级。
- `FILM_ORANGE`：允许明显胶片橙、橙红或暖黄成为主光带、主色域或关键辅助色；暗部用来源深色、普鲁士蓝或深蓝绿承接，禁止全局橙黄罩染。
- `PRUSSIAN_BLUE`：允许普鲁士蓝、靛蓝或雾蓝成为主场域与有色暗部；保留来源暖色或单一胶片橙作为局部回应，基底不能整体变蓝。

命名强色方向不是“额外滤镜”。胶片橙或普鲁士蓝必须承担第一落点、空间分离、运动路径、关系连接或冷暖张力中的至少一项功能。

## 3. 个人色彩校准关系

以下关系提炼自 Golden Sample 的色彩机制，只迁移关系，不复制题材和构图：

1. 暖象牙白或冷白基底 + 低饱和鼠尾草/矿物绿 + 丹宁蓝或普鲁士蓝。
2. 暖象牙白、冷白或纯白数字基底 + 灰青/浅蓝/海绿 + 单一珊瑚橙小锚点。
3. 普鲁士蓝/靛蓝/雾蓝灰的绘制区 + 局部胶片暖黄或橙色光迹。
4. 暖象牙白、淡沙色或白色底料基底 + 低饱和橙红 + 深蓝绿色有色暗部。

选择条件：

- 原图有清楚来源色时，以来源为主；鲜明来源色可以保留，只借用上述冷暖、明暗和面积关系。
- 原图接近无彩色时，根据时间、气候和核心识别色选择一组，不同时混用多组。
- 普鲁士蓝、胶片橙、橙红和暖黄可以成为主色或辅助色；第二强调色仍须克制，并且所有强色只在有构图功能的位置出现。

## 4. 画面比例

在“明确绘制区域”内部：

- 主色域约 60%–80%。
- 辅助色族约 15%–35%。
- 标准方向的局部强调色不超过约 10%，通常只出现一次主锚点和一次微弱回声。

当 `FILM_ORANGE` 或 `PRUSSIAN_BLUE` 被选为命名强色方向时，它可以进入主色域或辅助色域，不受 10% 强调色上限约束；但另一种竞争性强色仍按局部强调色控制。

`OPEN_SPACE` 中，所选基底的未覆盖区域不计入绘制色域。`QUIET_FILLED_FIELD` 中，覆盖基底的静默色域计入主色域，但必须来源明确、低对比且不形成全局滤镜。深色优先用普鲁士蓝、深蓝绿、灰褐或来源有色暗部，谨慎使用纯黑。

基底不是调色滤镜。人物肤色、棕色动物、木色、夕阳或暖灯已经提供暖锚点时，优先使用纯白、冷白或中性象牙白裸露基底；胶片橙、橙红和暖黄只能留在核心、记忆场或光迹的局部来源区域。不得用大面积暖黄纸面重复同一个暖关系。

## 5. 色彩与构图连接

- 核心持有最清楚的识别色或最强局部冷暖对比。
- 记忆场从来源色中回收一至两个弱化色，不能建立第二套调色板。
- 过渡痕迹或来源图形回声只能重复一次核心颜色或其邻近色，不能各自建立颜色回声。
- 强调色必须帮助第一落点、接触关系、运动方向或尺度判断，不能只填空。

## 6. Color Gates

1. 去掉颜色后，核心、记忆场、文字预留和低信息呼吸区域的灰度重量仍成立。
2. 去掉颜色后，如果媒介、眼动和情绪完全不变，说明颜色只是无效装饰，应删除或改为结构性色彩。
3. 基底必须符合 `surface` 定义：暖象牙白不泛黄，纯白数字板无纸纹，冷白棉纸不变办公纸，浅色纸不变全局色罩，白色底料画布不抢主体。
4. 禁止规则色卡、重复圆方色块、彩色贴片和与来源无关的综合色噪声。
5. 明显胶片橙或普鲁士蓝必须能指出其结构作用；如果只能用“氛围更好”解释，判定为无结构色罩并重做。
6. 裸露基底在灰度和色彩上都必须保持独立：不得被统一暖黄、蓝绿、雾灰或怀旧颗粒覆盖。若去掉核心与记忆场后仍只剩一张有色滤镜底，判定失败。
7. 核心已经包含肤色、棕色动物、木色或暖光时，暖色基底必须有不可替代的来源和构图理由；否则改用中性或冷白基底。
8. 对照原图检查 `dominant_relation`、`area_relation`、光源与材料响应；只保留一个身份强调色而丢失主色场或时空气氛，判定失败。
9. 纸面颜色不能成为新主色并覆盖来源味道；若原图的薄荷青天空、海绿水面、鲜绿草坡或暖光空间是内容资产，必须在成品中保持足够面积与因果关系。
