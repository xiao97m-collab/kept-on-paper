# Memory Title Editor

标题与短句可以发现照片里的诗意，但不能替照片编故事。本层只决定“写什么”；字体、材料、位置和字形由 `typography-and-language.md` 与 `lettering-engine.md` 处理。

核心原则：

> 事实是文案的起点，不是终点。文字不必全部是字面事实，但必须有视觉根源。

Source Fidelity 用来阻止胡编，不用来消灭诗意。好的文案应当看懂照片以后，替照片多说半句话。

## 1. 输出角色

只返回一种内容结构：

- `SHORT_TITLE`：自然、有记忆指向的短标题；中文通常 2–12 字，英文通常 1–6 词。
- `DEFINITION_LINE`：标题不能自然成立时，使用 8–24 个汉字或 4–12 个英文词的小号定义句。
- `TITLE_PLUS_LINE`：一个短标题加一句 8–30 个汉字的支持句。标题负责视觉命名或记忆锚定，小句负责不重复的情绪回应。
- `OFF`：以上结构均无法安全、具体、自然成立时保持无字；这是有证据的末级回退，不是默认选择。

`AUTO` 的基础回退链仍是 `SHORT_TITLE → DEFINITION_LINE → OFF`。短标题成立后，只有支持句通过独立检查、确实增加余味且不重复标题时，才升级为 `TITLE_PLUS_LINE`；不能把双层文字当海报模板。

`USER_TEXT` 逐字使用，不进入自动改写。来源画面中必须保留的可读文字、logo、招牌和符号属于 `SOURCE_EXACT_MARK`，不是创作文案，也不进入上述回退链；标题选择为 `OFF` 不能删除来源标志。

## 2. AUTO 文字需要门

先逐项计数；两个及以上普通信号成立，或一个不可替换的高特异信号成立，并且能用自然语言表达时，判定 `SHOULD_TITLE`：

- `HIGH_SPECIFICITY`：两个以上具体事实形成不可随意替换的组合，如双重视线、彩色路径通向一个小人物、多人动作越过山线。此项单独成立即可。
- 有明确动作、接触、并肩、等待、经过、抬头、举起、摆动或运动余迹。
- 人与环境之间存在可见尺度、方向、距离、冷暖、明暗或聚散张力。
- 一个来源色、光线、遮挡、反射、路径或形态构成视觉锚点，而非普通调色。
- 季节、天气、环境尺度与人的活动共同形成可感知的气质或反差。
- 高密度编辑构图需要文字建立海报层级，且具体文案能够成立。

单一弱信号不自动强加文字。普通站姿、泛化蓝天、常见日落或一般旅行背景只能触发候选尝试。若候选只能泛化，进入定义句；定义句仍不能增加准确意义时才 `OFF`。

只有同时满足以下条件才允许 `OFF`：

1. 已检查 2–4 个短标题候选及至少一个定义句候选；画面存在明确情绪张力时还要检查至少一个 `EMOTIONAL_ECHO`。
2. 每个候选都在 `FACT_TRACE`、`NATURAL_SPEECH`、`NARRATIVE_BOUNDARY`、`GROUNDED`、`RESONANT`、`SPECIFIC`、`GENERIC_SWAP` 或文字安全区中至少失败一项。
3. 内部记录 `candidate → failed gate → visible evidence`；不能只写“标题不如画面”或“无字更高级”。

没有安全艺术字区只意味着 `ART_LETTERING=OFF`，必须继续尝试规整标题或 `DEFINITION_LINE`。只有连小号定义句也会覆盖身份、动作、接触或破坏构图时，排字安全才可支持 `OFF`。

## 3. Fact Card

先从 Source Lock 提取，不先追求文学感：

```yaml
subject:
action_or_state:
relation_or_distance:
environment:
season_or_weather:
light:
color:
scale:
spatial_tension:
distinctive_visual_evidence: []
reasonable_visual_inferences: []
source_intrinsic_exact_marks: []
forbidden_narratives: []
```

`spatial_tension` 只能来自画面内同时成立的两种力量，如静止与流动、人与尺度、冷环境与暖色、聚集与孤立。不能确认的人物经历、关系、心理、目的、地点、日期、前因后果和人生意义写入 `forbidden_narratives`。

## 4. Reasonable Visual Inference

不要求所有语义都达到像素级证明。当一个判断同时满足以下条件，可以写入 `reasonable_visual_inferences`：

- 由多个明确视觉证据共同支持；
- 普通观看者大概率会形成相同判断；
- 不依赖隐藏背景资料；
- 没有继续推导具体地点、日期、人物身份或事件。

例如港池、小型船只、码头、防波堤、沿海建筑与积雪共同支持“冬日渔港”；没有 GPS、招牌或元数据时，不能继续写成“北海道冬日渔港”。合理视觉推断属于可用语义，不应为了绝对安全自动退化成更空泛的词。

## 5. Narrative Hallucination 与 Emotional Resonance

`NARRATIVE_HALLUCINATION` 继续严格禁止：不得替人物建立过去、未来、关系、动机、具体心理、人生阶段或事件因果；不得虚构地点、日期、告别、失恋、成长、重逢、归宿等故事。

`EMOTIONAL_RESONANCE` 明确允许：可以从真实存在的天气、季节、光线、颜色、尺度、距离、动作、空间、动静关系和整体气质中，形成适度的感官或情绪回应。它表达观看者被什么触发，不替画中人物宣布内心。

判断关键不是“这句话是不是字面事实”，而是：

```text
它能否从最终表达完整回溯到画面证据，且中途没有补出人物故事？
```

例如雪、冷海、红桥、黄色衣着和持续行走共同形成“冷环境中存在暖色与人的活动”，可以支持“海风很冷，但日子总会有温柔的光”。“日子有温柔的光”不是字面事实，但它是由冷暖与生命活动合成的观看感受，不是人物故事。

## 6. 候选生成

先写一句完全普通的照片描述，建立事实锚点；再生成 2–5 个候选，不默认任何家族优先：

- `VISUAL_NAMING`：为场景或独特的光、色、路径、形态命名。
- `FACT_TENSION`：点出画面内真实张力，如“小小的人，长长的路”。
- `ACTION_FRAGMENT`：保留最有记忆性的动作片段，如“等灯亮起”。
- `PLAIN_RESONANT`：普通但有余韵，如“灯还亮着”。
- `RELATION_DEFINITION`：定义可见关系，不替关系命名，如“并肩看向同一处”。
- `EMOTIONAL_ECHO`：不描述人物内心，不虚构具体故事；从天气、光线、颜色、尺度、动作或空间关系中提取情绪，用一句有余味的话回应画面。

候选不需要同时覆盖所有家族。根据照片选择能增加价值的家族；没有情绪张力时，不为完成流程硬写 `EMOTIONAL_ECHO`。

## 7. Fact Trace

诗意或情绪候选必须建立 `Fact Trace`，但不再机械计算联想次数。把关键语义标为三类：

- `OBSERVED`：照片直接可见。
- `REASONABLE_INFERENCE`：由多项证据稳定支持的普通判断。
- `EMOTIONAL_SYNTHESIS`：由可见的冷暖、明暗、尺度、距离、动作或空间张力形成的观看感受。

合格链路：

```text
雪景海港 + 深蓝冷海 → 冬季寒冷感
红桥 + 黄色人物 + 行走活动 → 冷环境中的暖色与生命活动
冷 × 暖 → 温柔仍然存在的情绪回应
→ 海风很冷，但日子总会有温柔的光。
```

不合格链路：

```text
一个人 → 孤独 → 人生困境 → 自我成长 → 和解
→ 人终究要学会与孤独和解。
```

后一条在“孤独”之后没有视觉证据，属于 Narrative Hallucination。`FACT_TRACE` 不要求每个词都是物理对象，但要求每一次语义变化都有可指出的视觉触发。

## 8. Grounded / Resonant / Specific

所有候选同时通过三个核心维度；三者没有谁自动压倒其余两项：

1. `GROUNDED`：能指出这句话由照片中的什么触发，并建立完整 Fact Trace。
2. `RESONANT`：是否在字面描述之外，为观看增加一点感受、理解或余味；纯事实标题可以通过，但在需要情绪回应的位置会被低分。
3. `SPECIFIC`：是否带有这张照片自己的环境、动作、色彩、尺度或关系，换图后不能原封不动成立。

再检查：

- `NATURAL_SPEECH`：像人会自然说的话，不为显得诗意而造句。
- `NARRATIVE_BOUNDARY`：没有人物经历、关系、心理、地点、日期或人生故事。
- `IMAGE_FIT`：语速、长短、冷暖与构图协调。
- `VALUE_ADD`：加入后是否比无字更值得记住。
- `OVERCLAIM`：只淘汰无证据的叙事、因果或具体断言；不能把一切非字面情绪都误判为 Overclaim。

事实矛盾或 Narrative Hallucination 是硬失败；字面事实更准确，不等于候选一定更好。一个具有完整 Fact Trace、强 Resonance 和足够 Specificity 的表达，不得仅因它不是字面描述而被主动改得更保守。

## 9. Generic Swap Test

对每个情绪候选做三次替换：

1. `SCENE_SWAP`：换成大量无关照片后，整句是否仍然成立？若是，淘汰。
2. `ANCHOR_REMOVAL`：删掉或替换场景锚点后，剩余句子是否仍是完整万能金句？若泛化部分成为主要语义，必须让场景证据承担更强作用或淘汰；若完整句的核心反差仍依赖不可替换的场景证据，可带风险通过。
3. `FORMULA_REUSE`：把具体名词抽掉后，是否只剩“X 很冷，但 Y 仍然温柔”“向着远方，寻找自由”等可反复套用的修辞骨架？单张只在具体锚点不可替换时通过；多图中复用同一骨架必须改写。

“温柔、治愈、自由、远方、美好、热爱、岁月、日子”等词不是禁词，但不能自己充当视觉证据。它们只有在同一句或标题—小句组合中被具体的天气、环境、颜色、动作或空间张力牢牢锚定时才可使用。

例如“愿所有美好如期而至”没有场景锚点，直接淘汰；“海风很冷，但日子总会有温柔的光”由“海风很冷”与画面里的冷暖反差锚定，可以保留，但同一批不能再为雨夜、雪山和咖啡馆复用“环境很冷 / 日子温柔”的骨架。若一组四张以上作品反复使用同一类“温柔 / 治愈 / 自由 / 远方”结论，逐张重做三项交换测试，优先换成各照片独有的感官或关系，不设机械禁词配额。

## 10. 标题与小句的职责

`TITLE_PLUS_LINE` 默认分工：

- 标题回答“这是什么”或“最值得记住的视觉关系是什么”，优先 `VISUAL_NAMING`。
- 小句回答“这些视觉证据让我感受到什么”，优先 `EMOTIONAL_ECHO`。

两者必须通过 `REDUNDANCY_CHECK`：删掉任意一层后，另一层仍成立；两层放在一起时提供不同信息。禁止“冬日渔港 / 一个下雪的冬日港口”这种重复。允许“冬日渔港 / 海风很冷，但日子总会有温柔的光”这种命名与回应。

画面只需要一个声音时选择单标题或单短句，不为版式丰富强行配对。标题与小句内容确定后，再独立决定视觉角色；不能让小句与标题争夺同一音量。

## 11. 排序、停止与 Hard Avoids

先淘汰事实矛盾、Narrative Hallucination 和断裂的 Fact Trace；剩余候选以 `GROUNDED + RESONANT + SPECIFIC` 共同决定，不再让事实字面度压倒其他指标。随后比较自然度、画面贴合、标题—小句互补性和新奇度；新奇度永远排在最后。

停止规则：

- 候选已经有根、有感、具体且自然：选择它，不为更安全自动降级。
- 文学版本缺乏视觉根源或不自然：选择普通版本。
- 短标题只能靠解释成立：改用 `DEFINITION_LINE`，不得直接 `OFF`。
- 标题成立但小句重复或泛化：保留 `SHORT_TITLE`，不使用 `TITLE_PLUS_LINE`。
- 2–4 个短标题与至少一个定义句全部有明确失败门，或连小号定义句也会覆盖受保护事实、破坏构图：`OFF`。

多图任务逐张判断，不共享一个全局 `OFF`。四张以上图片若超过约 75% 为 `OFF`，逐张复查是否遗漏动作、关系、路径、尺度、颜色锚点或可成立的情绪张力；这是异常复核，不是标题配额。若多数图片都落入同一种 `EMOTIONAL_ECHO`，按第 9 节重新执行交换测试。

Hard Avoids：

- 为人物编过去、未来、关系、心理、地点、日期或人生意义。
- 反常识奇喻、伪哲思、广告金句和无锚点社交媒体鸡汤。
- “治愈一切”“奔赴热爱”“岁月静好”“把生活过成诗”等可无差别套图的话术。
- 为押韵、对仗、双关或艺术字效果牺牲视觉根源。
- 用字体、颜色或视觉冲击掩盖文案空泛。
